# 🏋️ FitNotes Analytics Dashboard

Aplicación web *Mobile-First* diseñada para importar, analizar y visualizar los datos de entrenamiento exportados desde la app móvil **FitNotes**. 

Permite evaluar la progresión de cargas, estimar el 1RM, visualizar la distribución del trabajo muscular mediante un mapa corporal interactivo y controlar el volumen semanal/mensual.

---

## 🚀 Tecnologías

* **Backend:** [FastAPI](https://fastapi.tiangolo.com/) (Python 3.10+)
* **Base de Datos Analítica:** [DuckDB](https://duckdb.org/) (OLAP en memoria / SQLite analítico)
* **Frontend:** [SvelteKit](https://kit.svelte.dev/) + [Tailwind CSS](https://tailwindcss.com/)
* **Procesamiento de Datos:** Pandas / NumPy
